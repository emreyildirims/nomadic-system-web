# Nomadic System — Brand Website

Bilingual (Turkish / English) website for **Nomadic System**, an outdoor and fitness coaching brand.

Designed and developed by [Mehmet Emre Yıldırım](https://www.linkedin.com/in/mehmetemreyildirim).

## Features

- Turkish / English language toggle without page reload
- Editorial-style layout: hero, manifesto, founder story and program pages
- Program and sample plan pages with tabbed content, tables and nutrition cards
- Contact form, modals and smooth page transitions
- Scroll progress bar and responsive design

## Tech Stack

HTML5 · CSS3 (custom design tokens) · Vanilla JavaScript

## Structure

```
├── index.html               Home
├── hakkimizda.html          About
├── programlar.html          Programs
├── ornek-programlar.html    Sample programs
├── iletisim.html            Contact
├── script.js
└── style.css
```
